# 農園マップと樹木台帳 (farm-map / tree registry)

`/farm-map` は、**樹木台帳（レジストリ）**に登録された樹木を農園の地図上に配置し、
各樹木の最新の体調（健康/良好/注意/要管理/未観測）を色分けして表示します。

## 樹木台帳 (trees テーブル)

`backend/app/storage.py` の `trees` テーブルが樹木を管理します。

| カラム | 説明 |
|--------|------|
| `id` | PK |
| `user_id` | どの農家の樹木か（必須） |
| `tree_id` | 樹木ID（同じ農家内で一意。観測データと突合に利用） |
| `name` | 樹木名（任意） |
| `variety` | 品種（任意） |
| `row_num` / `col_num` | 畝/列（地図上の固定配置に使用） |
| `note` | 備考 |

登録・編集・削除は管理画面の「農園マップ」（樹木台帳テーブル）または API で行います。
**管理者は必ず `farmer_id` で対象農家を指定**する必要があります（`/api/trees/registry`）。

### API

| メソッド/パス | 説明 |
|---------------|------|
| `GET /api/trees/registry?farmer_id=4` | 農家4の樹木台帳一覧 |
| `POST /api/trees/registry?farmer_id=4` | 樹木登録（`{tree_id, name, variety, row_num, col_num, note}`） |
| `PUT /api/trees/registry/{tree_id}?farmer_id=4` | 更新（tree_id / row_num / col_num 等） |
| `DELETE /api/trees/registry/{tree_id}?farmer_id=4` | 削除 |
| `POST /api/trees/registry/import?farmer_id=4` | 観測済みの樹木IDを空きセルへ一括登録 |
| `GET /api/farm-map?farmer_id=4` | 農園マップ用データ（登録樹木＋観測状態） |

認証: 農家は自分の分のみ操作可。管理者は `farmer_id` 指定が必要。

### 農園マップの表示規則

- **表示グリッド**: 地図は **畝（行）2列 × 3列** を基本グリッドとして描画します
  （バックエンド `main.py` の `COLS = 3`、`CELL_W=118` / `CELL_H=130` / `PAD_X=PAD_Y=70`）。
  登録樹木が3列を超える場合は列数が増え、SVG の幅も自動で広がります。畝は最低2行を確保します。
- **台帳に登録済みの樹木**は `row_num` / `col_num` から決定的に計算した固定座標に
  配置されます。
  - 座標は `x = 70 + (col-1)*118 + 59`、`y = 70 + (row-1)*130 + 65` のグリッド。
- **観測にはあるが台帳に未登録の樹木**は、空きセルへ**行優先（row-major）**で自動配置され
  `registered: false` とマークされ、ノード選択後の詳細パネルから台帳へ登録できます。
  未登録の木が多い場合も、同じ3列グリッドの空きセルから順に埋めていきます。
- 各樹木は最新観測の体調で色分け（happy=緑 / good=黄緑 / caution=黄 / danger=赤 /
  未観測=グレー）。未登録の木は破線ボーダー、登録済みの未観測の木は実線ボーダーで表示します。クリックで観測回数・最終観測日時・状態メッセージを表示し、
  「観測履歴へ」リンクは `/tracking?tree=<tree_id>` に遷移します。

## サンプルデータの付与

動作確認用のサンプルとして、農家アカウントの `tree_id` 未設定観測に `A-01`〜`A-16` の
デモIDを振るスクリプトがあります。

```powershell
cd backend
.\.venv\Scripts\python.exe tools\assign_sample_tree_ids.py
```

このスクリプトは何度でも再実行でき、実解析で入力済みのIDは上書きしません
（実稼働のtree_idはそのまま）。なお `A-01`〜`A-16` は樹木台帳（`POST /api/trees/registry/import` 等）に
別途登録することで地図上に固定配置されます。

## 操作導線

1. **農園マップへアクセス**: `/farm-map` を開く
2. **農家選択（管理者のみ）**: 上部の「表示する農家」ドロップダウンから農家を選択
3. **樹木台帳から管理**: 画面下部の「樹木台帳（登録済み）」テーブルで、登録・編集・削除・一括import を実行
4. **マップ上で確認**: SVG 地図上の樹木ノードをクリックすると、詳細パネル（体調・配置・観測回数・最終観測）が表示
5. **未登録の木を登録**: マップ上の未登録ノードを選択して詳細パネルを表示し、「樹木を登録」から新規登録モーダルを開く
6. **観測済みの木を一括登録**: 「観測済みの木を自動登録」ボタンで、観測履歴にある未登録の樹木IDを空きセルへ一括登録
7. **観測履歴へ遷移**: 詳細パネルの「観測記録を見る」リンクから `/tracking?tree=<tree_id>` に遷移
8. **注意・要管理のみ強調**:  凡例エリアのチェックボックスでフィルタリング

## レスポンシブ対応

- SVG 地図は `viewBox` + `h-auto w-full` で画面幅に合わせて縮小表示
- 樹木台帳テーブルは `overflow-x-auto` で水平スクロール対応（最小幅 720px）
- ヘッダー・要約カードは `flex-wrap`, `grid` で画面幅に応じて詰める
- モーダルは `max-w-md` + `p-4` で小画面でも収まる

## 未観測状態の説明

- **未観測**: 最新の状態がなく、動画/画像解析による観測がまだない樹木。台帳登録済み・未登録のどちらでも該当します。
- 地図上ではグレーの塗りつぶし + 実線ボーダーで表示。
- 台帳テーブルの「最新状態」カラムには灰色の「未観測」テキストで表示。
- サマリーバーの「未観測」カードで未観測の本数を確認できる。
- **未登録**: 観測にはあるが台帳にまだ登録されていない状態。マップ上はグレー塗りつぶし + 破線ボーダーで表示され、「未登録」ラベルが付きます。ノード選択後の詳細パネルから登録フォームを開けます。
- 未観測の樹木は平均スコアや体調カウント（happy/good/caution/danger）に含まれません。「注意・要管理のみ強調」では、未観測の木も含めて表示し、観測済みの正常な木を薄く表示します。

## フロントの画面要素

- 地図（樹木ノード + クリックで詳細パネル）
- 樹木台帳テーブル（登録/編集/削除、新規登録モーダル、一括import）
- 集計カード（総樹木数 / 要管理・注意の本数）
- 「注意・要管理のみ強調」フィルタ
- 表示モード切り替え: あなたの農園 / 管理者は農家切り替え
